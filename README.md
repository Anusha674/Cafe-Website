# Cafe Website

A modern responsive cafe website built with React and Vite. The app presents a polished cafe experience with menu browsing, cart ordering, reservations, gallery browsing, reviews, authentication UI, and dark/light theme support.

## Features

- Responsive landing page for desktop and mobile
- Hero, menu, culinary experience, about, gallery, reservation, testimonials, and footer sections
- Searchable and filterable menu
- Quick add and detailed item view with quantity and notes
- Shopping cart drawer with order type, promo code, tax, delivery fee, and checkout flow
- Reservation form with validation and saved booking history
- Review submission modal
- Login/register modal using local browser storage
- Dark/light theme toggle
- Local persistence for cart, theme, user, orders, and reservations

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React icons
- Oxlint

## Getting Started

### Prerequisites

Install Node.js and npm.

### Installation

```bash
npm install
```

### Run Locally

```bash
npm run dev
```

### Open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

### Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```
